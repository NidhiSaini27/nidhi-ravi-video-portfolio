# Nidhi & Ravi — Video Editing Portfolio

A responsive React + Vite portfolio for Nidhi Saini (Lead Video Editor) and Ravi Chandel (Research & Story), built on the Roggy Sandor portfolio template.

The template's design, layout and `src/styles.css` are used exactly as supplied, unchanged. Only the written content was adapted, from designer / illustrator to video editing and storytelling.

## Run locally

```bash
npm install
npm run dev
```

## What's inside

- Home — intro, skills, experience, and an edit room section with selected work
- About — the duo behind the edits
- Case Study — Kuldhara: The Haunted Village, Talking Head Edits, and Horror & True Crime Reels
- Playground — text animation, grade studies, sound and editing experiments
- Contact — project enquiry form (client-side validation only, as in the template; connect a form service or backend to receive submissions)
